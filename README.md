# Ford Used Car Price Prediction

## 📌 Project Overview

This project predicts the selling price of used Ford cars using
machine learning techniques.

The project analyzes factors such as:

- Vehicle model
- Year
- Mileage
- Engine size
- Fuel type
- Transmission
- MPG
- Tax

## 🎯 Objectives

- Analyze factors affecting used-car prices
- Perform exploratory data analysis
- Clean and preprocess the dataset
- Build regression models
- Compare model performance
- Identify the best-performing model

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Exploratory Data Analysis

The analysis examines:

- Price distribution
- Price vs mileage
- Price vs vehicle year
- Price vs engine size
- Price by fuel type
- Price by transmission
- Correlation between numerical variables

## 🤖 Machine Learning Models

The following regression models are evaluated:

1. Linear Regression
2. Polynomial Regression

## 📈 Evaluation Metrics

Models are evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## 💡 Key Insights

The analysis identifies the major factors influencing
used Ford car prices, including vehicle age, mileage,
model, engine size and fuel type.
